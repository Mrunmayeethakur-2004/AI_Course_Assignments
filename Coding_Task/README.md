# Coding Task – Python Fundamentals

This folder contains solutions to a set of core Python programming exercises, implemented and run in Google Colab. The tasks cover control flow, data structures, dictionaries, and comprehensions.

## Tasks

### Section 1: Basics
1. **FizzBuzz Challenge** — Print Fizz/Buzz/FizzBuzz for numbers 1–50 based on divisibility by 3 and 5.
2. **Leap Year Logic** — Function to check whether a given year is a leap year.
3. **Identity vs Equality** — Explains the difference between `==` (value equality) and `is` (object identity) using two equal lists.
4. **Bitwise Swap (Advanced)** — Swaps two numbers using XOR, without a third variable.

### Section 2: Control Flow & Loops
5. **Prime Number Finder** — Uses a while loop to find and print the first 10 prime numbers.
6. **The Loop Breaker** — Demonstrates `pass`, `continue`, and `break` in a single loop from 1–20.
7. **Nested Conditionals** — Converts a numerical grade (0–100) into a letter grade (A/B/C/Fail).
8. **Reverse an Integer** — Reverses the digits of an integer using `//` and `%` in a while loop.

### Section 3: Data Structures (Lists, Tuples, Sets)
9. **Runner-Up Score** — Finds the second-highest score in a list without using `sort()` or `sorted()`.
10. **Duplicate Removal** — One-line removal of duplicate values from a list.
11. **List Intersection** — Finds common elements between two lists using the `in` operator.
12. **Tuple Immutability Test** — Attempts to modify a tuple and handles the resulting `TypeError` with try-except.

### Section 4: Dictionaries & Comprehensions
13. **Character Frequency Counter** — Builds a dictionary of character counts from a string.
14. **List Comprehension** — Generates squares of all even numbers between 1 and 20 in one line.
15. **Dictionary Comprehension** — Filters a dictionary to keep only items with values greater than 2.

## How to run

Open `Coding_Task.ipynb` in Google Colab and run all cells from top to bottom. Each task is self-contained in its own cell with example outputs printed below it.

## Outputs

Each task prints its result directly below its code cell, including test cases where applicable (e.g. leap year checks, grade conversions, reversed integers).
