# ML Assignment

This repository contains solutions for four machine learning tasks, implemented and run in Google Colab.

## Tasks

1. **Random Forest — Breast Cancer** (sklearn dataset)
2. **Logistic Regression — Diabetes** (Pima Indians Diabetes dataset)
3. **XGBoost — Titanic** (Titanic dataset)
4. **Decision Tree — Diabetes** (Pima Indians Diabetes dataset)

## How to run

Open `ML_Assignment.ipynb` in Google Colab and run all cells from top to bottom. Datasets are downloaded automatically within the notebook (except the breast cancer dataset, which loads directly from sklearn).

## Outputs

Each task prints accuracy, confusion matrix, precision/recall/F1, ROC-AUC, and feature importances/coefficients directly below its code cell.
